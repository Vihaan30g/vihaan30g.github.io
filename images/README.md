# Images

File names are set in the data files, so name your pictures exactly as written there (case-sensitive).

- `images/hero/me.jpg`  : your photo
- `images/projects/`    : cover pictures, file name = the `image:` value in `data/projects.js`
- `images/certificates/`: file name = the `image:` value in `data/certificates.js`
- `images/achievements/`: file names = the `photos:` list in `data/achievements.js`

To add a new picture: upload it to the folder, then add its file name to the matching data file.
